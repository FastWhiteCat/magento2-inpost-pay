# InPost Pay Commerce for Magento 2

Adobe Commerce support package for the InPost_InPostPay module.

## Installation

```bash
composer require inpost/magento2-module-inpost-pay-commerce
bin/magento module:enable InPost_InPostPayCommerce
bin/magento setup:upgrade
```
