# InPost Pay GraphQL for Magento 2

Module implements GraphQL endpoints for the InPost_InPostPay module.

## Installation

```bash
composer require inpost/magento2-module-inpost-pay-graph-ql
bin/magento module:enable InPost_InPostPayGraphQl
bin/magento setup:upgrade
```
