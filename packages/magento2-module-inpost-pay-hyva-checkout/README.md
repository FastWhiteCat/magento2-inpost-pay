# InPost Pay Hyva Checkout for Magento 2

InPost Pay integration for Hyva Checkout.

## Installation

```bash
composer require inpost/magento2-module-inpost-pay-hyva-checkout
bin/magento module:enable InPost_InPostPayHyvaCheckout
bin/magento setup:upgrade
```
